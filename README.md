# Chemistry Lab

A Java application designed to simulate chemical reactions in an interactive and educational way.

## About

**Chemistry Lab** is an interactive chemistry simulation developed in Java. The project allows users to experiment with chemical compounds, generate new compounds automatically, and classify the reactions that occur.

It was designed as both a programming project and an educational tool for exploring fundamental concepts of chemical reactions.

## Features

* **Chemical Reaction Simulation** — Simulate chemical reactions in an interactive environment.
* **Automatic Compound Generation** — Generate compounds automatically for experimentation.
* **Reaction Classification** — Identify and classify different types of chemical reactions.
* **Educational Approach** — Explore chemistry concepts through interactive simulations.

## Technologies

* **Java** — Application development and reaction simulation.
* **MySQL** — Data storage and management.

## Getting Started

### Prerequisites

Make sure you have the following installed:

* Java Development Kit (JDK)
* MySQL
* Git

### Installation

Clone the repository:

```bash
git clone https://github.com/lucfercosta/Chemistry-Lab.git
cd Chemistry-Lab
```

Configure the MySQL database according to the project's database configuration, then build and run the Java application using your preferred Java IDE or build environment.

## How It Works

The application combines a Java-based simulation with a MySQL database to provide an interactive chemistry experience:

1. Compounds are generated or selected.
2. The application determines whether a reaction can occur.
3. The reaction is simulated.
4. The resulting compounds are generated.
5. The reaction is classified according to its type.

## Project Goals

The main goals of Chemistry Lab are to:

* Practice object-oriented programming with Java.
* Model chemical concepts through software.
* Work with relational databases using MySQL.
* Create an interactive learning experience.
* Automate the generation and classification of chemical reactions.
